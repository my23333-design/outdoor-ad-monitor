# 数据可视化大屏数据映射规则

## 1. 概述

本文档定义了广告业务系统数据到数据可视化大屏的映射规则，确保数据准确性和一致性。

## 2. 业务节点与数据源

### 2.1 广告初审系统
- **数据表**: advertisement
- **关键字段**: audit_status, create_time
- **数据用途**: 审核状态统计、在线率计算

### 2.2 合法广告数据库
- **数据表**: advertisement
- **关键字段**: audit_status = '1', handle_status
- **数据用途**: 合法广告数量、媒体类型统计

### 2.3 存疑广告管理模块
- **数据表**: advertisement
- **关键字段**: handle_status in ('0', '1', '2')
- **数据用途**: 待处理、处理中、复审中广告统计

### 2.4 叫停广告记录系统
- **数据表**: advertisement
- **关键字段**: handle_status = '4'
- **数据用途**: 叫停广告数量、区域分布

### 2.5 复审管理平台
- **数据表**: advertisement
- **关键字段**: handle_status = '2'
- **数据用途**: 复审中广告统计

### 2.6 执行结果报表
- **数据表**: advertisement
- **关键字段**: handle_status, update_time
- **数据用途**: 处理结果统计、月度趋势

## 3. 大屏模块数据映射

### 3.1 左上角：各区违法广告数量
- **数据源**: 存疑广告管理模块 + 叫停广告记录系统
- **映射规则**:
  ```sql
  SELECT district, COUNT(*) as count
  FROM advertisement
  WHERE handle_status IN ('0', '1', '2', '4')
  AND create_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  GROUP BY district
  ORDER BY count DESC
  LIMIT 5
  ```
- **数据格式**: [{name: '区域名', value: 数量}]
- **更新频率**: 5分钟

### 3.2 左下角：违法行业数量
- **数据源**: 存疑广告管理模块 + 叫停广告记录系统
- **映射规则**:
  ```sql
  SELECT ad_industry_type, COUNT(*) as count
  FROM advertisement
  WHERE handle_status IN ('0', '1', '2', '4')
  AND create_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  GROUP BY ad_industry_type
  ORDER BY count DESC
  LIMIT 8
  ```
- **数据格式**: [{name: '行业名', value: 数量}]
- **更新频率**: 5分钟

### 3.3 中间：石家庄各区广告数量（地图）
- **数据源**: 合法广告数据库 + 叫停广告记录系统
- **映射规则**:
  ```sql
  SELECT district, COUNT(*) as count
  FROM advertisement
  WHERE create_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  GROUP BY district
  ```
- **数据格式**: [{name: '区域名', value: 数量}]
- **更新频率**: 5分钟

### 3.4 右上角：违规广告媒体类型
- **数据源**: 合法广告数据库
- **映射规则**:
  ```sql
  SELECT ad_medium_type, COUNT(*) as count
  FROM advertisement
  WHERE create_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  GROUP BY ad_medium_type
  ```
- **数据格式**: [{name: '媒体类型', value: 数量}]
- **更新频率**: 5分钟

### 3.5 右中：广告类型月度统计
- **数据源**: 执行结果报表
- **映射规则**:
  ```sql
  SELECT 
    DATE_FORMAT(create_time, '%Y-%m') as month,
    SUM(CASE WHEN ad_profitability_type = '1' THEN 1 ELSE 0 END) as commercial,
    SUM(CASE WHEN ad_profitability_type = '2' THEN 1 ELSE 0 END) as public,
    SUM(CASE WHEN ad_profitability_type = '3' THEN 1 ELSE 0 END) as government,
    SUM(CASE WHEN ad_profitability_type IS NULL THEN 1 ELSE 0 END) as other
  FROM advertisement
  WHERE create_time >= DATE_SUB(NOW(), INTERVAL 6 MONTH)
  GROUP BY month
  ORDER BY month
  ```
- **数据格式**: {month: {commercial: 数量, public: 数量, government: 数量, other: 数量}}
- **更新频率**: 5分钟

### 3.6 右下角：最新违法信息
- **数据源**: 叫停广告记录系统
- **映射规则**:
  ```sql
  SELECT 
    CONCAT('W', id) as id,
    LEFT(ad_description, 20) as content,
    district,
    DATE_FORMAT(create_time, '%Y-%m-%d %H:%i:%s') as createTime
  FROM advertisement
  WHERE handle_status = '4'
  ORDER BY create_time DESC
  LIMIT 5
  ```
- **数据格式**: [{id: 'W40', content: '描述', district: '区域', createTime: '时间'}]
- **更新频率**: 实时

### 3.7 底部：各区违法广告状态数量
- **数据源**: 存疑广告管理模块 + 复审管理平台 + 执行结果报表
- **映射规则**:
  ```sql
  SELECT 
    district,
    SUM(CASE WHEN handle_status = '0' THEN 1 ELSE 0 END) as pending,
    SUM(CASE WHEN handle_status = '1' THEN 1 ELSE 0 END) as processing,
    SUM(CASE WHEN handle_status = '2' THEN 1 ELSE 0 END) as reviewing,
    SUM(CASE WHEN handle_status = '3' THEN 1 ELSE 0 END) as finished,
    SUM(CASE WHEN handle_status = '4' THEN 1 ELSE 0 END) as stopped
  FROM advertisement
  WHERE create_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  GROUP BY district
  ORDER BY (pending + processing + reviewing + finished + stopped) DESC
  ```
- **数据格式**: [{name: '区域名', pending: 数量, processing: 数量, reviewing: 数量, finished: 数量, stopped: 数量}]
- **更新频率**: 5分钟

## 4. 状态码映射

### 4.1 审核状态 (audit_status)
- '0': 未审核
- '1': 已通过
- '2': 审核中
- '3': 已拒绝
- '4': 已叫停
- '5': 已过期
- '6': 已删除
- '7': 待复审
- '8': 复审通过

### 4.2 处理状态 (handle_status)
- '0': 待处理
- '1': 处理中
- '2': 复审中
- '3': 已完成
- '4': 已叫停

### 4.3 广告盈利类型 (ad_profitability_type)
- '1': 商业广告
- '2': 公益广告
- '3': 政务广告
- null: 其他

## 5. 数据校验规则

### 5.1 必填字段校验
- 广告名称 (ad_name): 不能为空
- 所属区域 (district): 不能为空
- 审核状态 (audit_status): 必须为有效值
- 创建时间 (create_time): 不能为空，不能晚于当前时间

### 5.2 数据范围校验
- 在线率: 0-100%
- 效果指数: 0-100
- 数值型字段: 不能为负数

### 5.3 数据一致性校验
- 调查时间不能早于创建时间
- 更新时间不能早于创建时间
- 状态转换必须符合业务规则

## 6. 数据同步策略

### 6.1 全量同步
- **触发条件**: 系统启动、数据过期
- **同步频率**: 每5分钟
- **同步内容**: 所有广告数据

### 6.2 增量同步
- **触发条件**: 定时任务
- **同步频率**: 每1分钟
- **同步内容**: 最近更新的数据

### 6.3 缓存策略
- **缓存时间**: 5分钟
- **缓存失效**: 数据更新或过期
- **缓存清理**: 定时清理过期数据
